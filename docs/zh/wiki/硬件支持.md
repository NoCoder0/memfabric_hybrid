# 硬件支持

本文按产品系列和具体机型列出 MemFabric Hybrid 支持的传输协议。

不同机型组成异构环境时通过 RDMA 互联，可以根据实际拓扑组合使用
`host_rdma` 和 `device_rdma`。

## A2

### Atlas 800T A2 / Atlas 800I A2

- `host_shm`
- `host_tcp`
- `host_rdma`
- `device_rdma`
- `sdma`：支持单机内 HBM 访问
- `mte`：支持单机内访问

### Atlas 200T A2 Box16

- `host_shm`
- `host_tcp`
- `host_rdma`
- `device_rdma`
- `sdma`：支持 8 卡内 HBM 访问
- `mte`：支持 8 卡内访问

### A2 over NPU RDMA网络（device_rdma）配套底软

| 配套要求 | 要求 |
| --- | --- |
| 灵衢 L1 LingQu Computing Network | 不依赖 |
| HDK | >=25.5.1 |
| HDK-firmware | 不涉及 |
| PageSize | 4K，64K 需开发确认 |
| OS kernel | 不涉及 |
| BIOS | 不涉及 |
| 集群规模 | 16 节点 |

### A3 over HCCS网络（device_sdma）配套底软

| 配套要求 | 要求 |
| --- | --- |
| 灵衢 L1 LingQu Computing Network | >=1.5.0，优选 1.5.1 |
| HDK | >=25.5.1 |
| HDK-firmware | >=7.8.0.6.201 [^1] |

| 集群规模 | 超节点内 |

### 配套底软

当前兼容性基线暂未提供 A5 的底软版本要求，后续补充。

## 底软检查方法

| 配套要求 | 版本链接 | 检查方法 |
| --- | --- | --- |
| 灵衢 L1 LingQu Computing Network | [LingQu Computing Network 版本][lingqu-version] | [查询当前灵衢 L1 软件版本][lingqu-check] |
| HDK | [HDK 版本][hdk-version] | `npu-smi info` |
| HDK-firmware | - | [^2] |
| PageSize | - | `getconf PAGESIZE` |
| OS kernel | [兼容性查询][os-compatibility] | `uname -a` |
| BIOS | [升级参考][bios-upgrade]（仅参考，以指导书为准） | `dmidecode -t bios` |
| 集群规模 | - | - |

[lingqu-version]:
    https://support.huawei.com/enterprise/zh/ascend-computing/lingqu-computing-network-pid-258003841/software
[lingqu-check]: https://support.huawei.com/enterprise/zh/doc/EDOC1100536709/ee774920
[hdk-version]: https://support.huawei.com/enterprise/zh/undefined/ascend-hdk-pid-252764743/software
[os-compatibility]: https://www.hiascend.com/hardware/compatibility
[bios-upgrade]: https://gitcode.com/Ascend/memcache/wiki/MemCache扩大A3可用内存空间.md

[^1]: 一般正常安装 HDK 后，此配套是准确的；如果 HDK 版本、灵衢交换机版本均正确，
    但出现 `sdma move comperr`，可检查此配套。
[^2]: 检查命令：
    `/usr/local/Ascend/driver/tools/upgrade-tool --device_index -1 --component -1 --version`
[^3]: 典型内存配置：1 TB（必须升级）；1.5 TB/2 TB（建议升级扩展更大空间）；
    3 TB（无需升级）。
